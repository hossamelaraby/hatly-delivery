# موقع وتطبيق توصيل شركة هاتلي (Hattly) 🛵💛

نظام متكامل لتوصيل الطلبات لشركة **هاتلي (Hattly)** يشمل:
1. **واجهة العميل للطلب المباشر** المتطابقة مع التصميم والألوان المرفقة بالصور.
2. **لوحة تحكم وإدارة فورية (Dashboard)** لمتابعة الطلبات لحظياً والبحث برقم الأوردر وطباعة البونات.
3. **حساب تلقائي لأسعار التوصيل**:
   - طلب فردي: 15 - 20 جنيه.
   - طلب مجمع: زيادة 5 جنيه على كل مكان إضافي.
4. **تكامل كامل مع واتساب**: توليد رسالة منظمة برقم الأوردر والتفاصيل كاملة والتوجيه لأرقام خدمة العملاء.
5. **مواعيد العمل**: من 7:00 صباحاً وحتى 4:00 بعد منتصف الليل مع مؤشر حالة فوري (متاح / مغلق).

---

## 🚀 روابط التشغيل السريع

- **موقع طلب العميل**: [http://localhost:3005](http://localhost:3005)
- **لوحة التحكم والإدارة (Admin Dashboard)**: [http://localhost:3005/admin](http://localhost:3005/admin)

├── public/
│   ├── assets/
│   │   ├── logo.png       # شعار هاتلي الرسمي

├── server.js              # خادم Express والـ API
